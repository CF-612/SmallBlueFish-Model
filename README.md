# SmallBlueFish-Model

小肥鱼模型的制作、修复与版本归档。项目仍在制作中，仓库里的旧版工程不是最终发布模型。

- 当前模型仍在继续调整；本批归档不代表最新制作状态。

## 恢复旧版

需要 Python 3.10+ 和 `zstd` 命令行工具（已用 Zstandard 1.5.7 测试）。克隆或下载仓库后，在仓库目录运行：

```sh
sha256sum -c SHA256SUMS
python3 restore.py --verify-only
```

确认全部通过后，恢复到指定的工程根目录：

```sh
python3 restore.py --destination /path/to/whale-model-prep
```

脚本会按 `MANIFEST.json` 自动拼接 8 个基准分片，再恢复各版本并校验原始 SHA-256。完整恢复需约 1.1 GB 空间，另留约 68 MB 临时空间；已有不同内容的文件不会被覆盖。

这些工程使用 Blender 5.2.3 保存，贴图已内嵌。版本清单与各文件校验值见 [`MANIFEST.json`](MANIFEST.json)。
